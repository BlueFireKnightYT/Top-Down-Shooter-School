# Top Down Shooter School

This game was developed as part of a school project. Our primary focus was on implementing raycasting and lighting.

We were allotted two weeks to create, test, and present the game.

My most significant learning experience during this project was related to lighting. I had not previously utilized Unity's light and shadow system, and I now possess a much deeper understanding of it. I also gained proficiency in using Unity's particle system.
